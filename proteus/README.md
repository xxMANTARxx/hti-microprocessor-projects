# Proteus designs

Follow the [Proteus Design Guide (PDF)](Proteus_Design_Guide.pdf).

- **Smart Safe:** full simulation in Proteus 8 (ATMEGA32 + `smart_safe.hex`, internal RC 1 MHz).
- **Smart AI Irrigation:** schematic only (Proteus cannot run the ESP32 Wi-Fi code).

Put the exported pictures and the `.pdsprj` files in this folder:
`proteus_safe_schematic.png`, `proteus_safe_simulation.png`, `proteus_irrigation_schematic.png`.
